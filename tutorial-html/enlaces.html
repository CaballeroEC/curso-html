a href="html_images.asp">HTML Images

a href="/css/default.asp">CSS Tutorial

Un archivo .asp es una página web que se ejecuta en un servidor (como Internet Information Services) usando Active Server Pages, no directamente en tu computadora.
Si lo abres localmente, el navegador no puede procesarlo. Además, los enlaces pueden fallar si no tienes los archivos o carpetas correctos. También importa que la estructura de rutas sea igual a la del servidor. Por eso necesitas un entorno web configurado para que funcione.
