Definición de colores.

De igual tipo de color que "TOMATO".

rgb(255,99,71)

#ff6347

hsl(9,100%,64%)

De igual tipo de color que "TOMATO" pero con un 50% de transparencia.

rgba(255,99,71,0.5)

hsla(9,100%,64%,0.5)

Además de los nombres de color predefinidos, los colores se pueden especificar utilizando RGB, HEX, HSL, o inculos colores transparentes utilizando valores de color RGBA o HSLA.

Valores de color RGB.

Se puede especifivar un color utilizando la fórmula: rgb(rojo, verde, azul)

rgb(255,0,0)

rgb(0,0,255)

rgb(60,179,113)

rgb(238,130,238)

rgb(255,165,0)

rgb(106,90,205)

Tonos de gris en RGB.

Los tonos de gris a menudo se definen utilizando valores iguales para los tres parámetros.

rgb(60,60,60)

rgb(100,100,100)

rgb(140,140,140)

rgb(180,180,180)

rgb(200,200,200)

rgb(240,240,240)

Valores de color RGBA

Un valor de color RGBA se especifica con: rgb(rojo, verde, azul, alfa)

El parámetro alfa es un número entre 0.0 (totalmente transparente) y 1.0 (nada transparente):

rgba(255,99,71,0)

rgba(255,99,71,0.)

rgba(255,99,71,0.4)

rgba(255,99,71,0.6)

rgba(255,99,71,0.8)

rgba(255,99,71,1.0)

Valores de color HEX

Se puede especificar un color utilizando un valor hexadecimal de la forma: #rrggbb

#ff0000

#0000ff

#3cb371

#ee82ee

#ffa500

#6a5acd

Valores de color HSL.

Un color se puede especificar utilizando el tono, la saturación y la luminosidad de la siguiente forma: hsl(tono, saturación, luminosidad)

Los valores del tono rondan entre los 0 y 360.

Los valores de saturación rondan entre el 0% y el 100%

Los valores de luminosidad rondan entre el 0% y el 100%

hsl(0,100%,50%)

hsl(240,100%,50%)

hsl(147,50%,47%)

hsl(300,76%,72%)

hsl(39,100%,50%)

hsl(248,53%,58%)

Valores de saturación.

La saturación describe como es la intencidad del color.

hsl(0,100%,50%)

hsl(0,80%,50%)

hsl(0,60%,50%)

hsl(0,40%,50%)

hsl(0,20%,50%)

hsl(0,10%,50%)

Valores de luminosidad.

La luminosidad de un color se puede describir con la cantidad de luz que se desea darle.

hsl(0,100%,0%)

hsl(0,100%,25%)

hsl(0,100%,50%)

hsl(0,100%,75%)

hsl(0,100%,90%)

hsl(0,100%,100%)

Tonos de gris en HSL.

hsl(0,0%,20%)

hsl(0,0%,30%)

hsl(0,0%,40%)

hsl(0,0%,60%)

hsl(0,0%,70%)

hsl(0,0%,90%)

Valores de color RGBA

Los valores de color HSLA son una extensión de los valores de color HSL, con un canal alfa que especifica la opacidad de un color: hsla(tono, saturacion, luminosidad, alfa)

hsla(9,100%,64%,0)

hsla(9,100%,64%,0.2)

hsla(9,100%,64%,0.4)

hsla(9,100%,64%,0.6)

hsla(9,100%,64%,0.8)

hsla(9,100%,64%,1)
